Prueba la resolución atómica de pases usando tus credenciales de administrador directamente contra la API REST.

1. Check-in Individual en Tiempo Real

Petición enviada inmediatamente por la app Android tras detectar un código QR con la cámara.

POST /api/eventos/:eventoId/checkin Authorization: Bearer <TOKEN_ADMIN_O_STAFF> Content-Type: application/json { "qrCode": "EP-7B1A2C3D4E5F6071" }

2. Sincronización en Lote (Offline Batch Sync)

Despachada automáticamente cuando el dispositivo recupera la conexión a internet.

POST /api/checkin/sync Authorization: Bearer <TOKEN_STAFF> Content-Type: application/json { "checkins": [ { "idLocal": "f18b3e80-72cb-42a1-a4b5-123456789abc", "eventoId": "651f1234567890abcdef1234", "qrCode": "EP-7B1A2C3D4E5F6071", "timestampLocal": "2026-10-22T17:30:00.000Z" } ] }
